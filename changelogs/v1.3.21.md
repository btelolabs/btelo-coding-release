## Improvements

- **Codex approval prompts** — Codex sessions now surface command, file, and permission approval requests as clear in-chat choices.
- **Skill discovery** — Codex now reads project and global skills from `.codex/skills` first while keeping existing `.agents/skills` locations as a fallback.
- **Long message input** — the chat input now caps its height and scrolls internally for long pasted or composed messages, keeping the send button visible.

## Bug Fixes

- Fixed prompt replies being sent as normal chat messages when a Codex approval was waiting for a selected answer.
