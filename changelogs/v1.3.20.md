## What's New

- **Expand Dynamic Island on completion** — a new toggle in Notifications settings lets you control whether finished sessions briefly expand the Dynamic Island card. Doing/done state and the always-on Dynamic Island indicator are unchanged.

## Improvements

- **One sound, every time** — completion notifications now ring exactly once via APNs using the ringtone you picked in settings, whether the app is in foreground, background, or you're on the lock screen. No more double-rings or accidental silence.
- **No more keyboard interruptions** — foreground notifications no longer pop a banner, so the keyboard stays up while you're typing. You'll still see the Dynamic Island update, hear the sound, and find the entry in Notification Center.
- **Test button always works** — the "Test Stacked Alarms" button on the Notifications page is now tappable regardless of whether the Completion Alarm switch is on, so you can preview the alarm sound any time.

## Bug Fixes

- Fixed completion sound not playing in some scenarios when the app was open on the same session — the Dynamic Island and APNs paths no longer mute each other.
