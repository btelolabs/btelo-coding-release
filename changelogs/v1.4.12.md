## What's New

- Images produced while the assistant works now appear inline in the chat — when it reads an image file, or when a tool writes one (a screenshot, a chart) and mentions where it saved it.
- Tap any image to view it full screen.

## Improvements

- Images are automatically shrunk to a mobile-friendly size before sending, so they load fast and use little data.
