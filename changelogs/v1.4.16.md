## What's New

- Interactive Claude sessions now work on Linux and on Windows via WSL — previously this only ran on macOS. If you run the server inside WSL, full interactive sessions are now supported.
- Simplified the install instructions on the website: one command works for macOS, Linux, and Windows (WSL), with no operating-system tabs to click through.
